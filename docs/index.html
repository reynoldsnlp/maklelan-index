About this index

This site is an unofficial, searchable index of scripture references in Dan McClellan's (@maklelan) YouTube videos. Dan McClellan is a biblical scholar who posts short videos on the Hebrew Bible, the New Testament, biblical languages, textual criticism, and the academic study of religion.

Type any Bible reference — for example Genesis 1:1, Exodus 20, Psalm 22, Isaiah 53, Matthew 5, John 3:16, Romans 8, or 1 Corinthians 15 — to find every video and timestamp where Dan McClellan discusses that passage. Clicking a result opens the YouTube video at the exact moment the reference is mentioned.

The index is built automatically from video transcripts (closed captions) and updated weekly. It is not affiliated with Dan McClellan or the @maklelan channel. See the GitHub repository for source code and details.
